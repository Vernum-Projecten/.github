## Software engineering from the Netherlands

Vernum Projecten B.V. builds software for work that has to be exactly right,
where a wrong answer is worse than no answer at all.

Every rule a system of ours answers to is read from the source that publishes
it, and cited in the code where it is implemented. What a program cannot
prove, it refuses to guess.

Most of our work is private to the people it is built for.
